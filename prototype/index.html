This is a concept, not the real tool. I made it as a design exercise after reviewing the Data Center Policy Navigator from Climate Cabinet Education (tamingdatacenters.com). It only covers Virginia and Texas, and the sample data was copied by hand from the live tool on 25 Nov 2026. I haven't checked it against the original sources, so please don't use it for real decisions.

    How are these ranked?

    This is my own simple rule, not Climate Cabinet's method. Each protection gets points for matching what you picked (more for your first pick), more points if your state has nothing in place, fewer if it only has part of it, and none if it's already in place. If you said which stage a project is at, protections for that stage get a small boost. The three highest scores go under "Start here".
